▶ Advanced — Wake Word Timing EXPAND
WAKE_WORD_SILENCE_SEC
0.55s
How long Phase-1 waits for silence before deciding you've finished the wake phrase. Lower = faster response, but raise it if the wake word gets cut off mid-phrase.
WAKE_WORD_TRIGGER_SEC
0.15s
How long you must be speaking before Phase-1 starts recording. Raise it if background noise keeps triggering false starts.
WAKE_WORD_MAX_RECORD_SEC
2.5s
Maximum length of the Phase-1 clip sent for wake-word matching. Raise it if you have a longer wake phrase that's getting truncated.
WAKE_WORD_LISTEN_SEC
12s
After the wake word is recognized, how long Phase-2 listens for your command before giving up and going back to sleep.
